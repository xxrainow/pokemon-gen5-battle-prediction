통합 파일은 `all_basic.parquet`, `all_basic.csv`다. 포맷별 파일은 `ubers_basic.parquet` 등이며, OU 3개 부분은 `ou_basic.parquet`로 합쳤다.

`battle_id`, `formatid`, `uploadtime`, `winner`는 관리 정보이고 `y`는 정답이다. `winner`와 `y`를 모델 입력에 넣으면 안 된다. 포맷의 입력 사용 여부는 별도 결정한다.

`uploadtime`은 원본의 업로드 Unix 시각을 그대로 보존했다. 시간순 분할·시기별 분포 확인에 사용할 수 있지만 경기 발생 시각과 동일하다고 가정하지 않는다. 모델 입력에는 자동으로 포함하지 않는다.

`type2` 빈칸은 단일 타입일 수 있어 유지했다. 기술·아이템·특성·레이팅은 제거했다. 숫자 인코딩·표준화·분할·조합 피처 생성은 아직 하지 않았다.

## 제외 내역

- `winner_not_1_or_2`: 33,872행
- `formatid_missing_or_unexpected`: 5행

제외 행의 원본 파일·행 위치·ID·이유는 `excluded_rows.csv`에 있다. 원본 파일은 수정하지 않았다. 상세 집계와 원본 해시는 `quality_report.json`, 컬럼 목록은 `columns.json`에 있다. 저장 후 통합 Parquet와 CSV의 전체 값을 직렬화 해시로 대조했고, 포맷별 행 수와 스키마도 확인했다.
