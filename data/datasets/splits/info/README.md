# 학습 검증 테스트 분할

전략: `matchup`, seed: 42. 기존 입력 컬럼과 값은 유지하고 경기 행만 나눴다.

| 분할 | 경기 수 | 비율 |
|---|---|---|
| train | 575,697 | 70.00% |
| validation | 123,361 | 15.00% |
| test | 123,361 | 15.00% |

같은 포맷의 같은 대진은 팀 순서를 바꿔도 하나의 그룹이다. matchup 전략에서는 한쪽 팀이 다른 상대와 싸운 경기가 다른 분할에 존재할 수 있다. team-components 전략은 같은 포맷의 팀 구성까지 서로 겹치지 않게 한다.

데이터는 `../data/train.parquet` 등으로 저장했다. `assignments.parquet`에는 원본 행·경기 ID·포맷·배정 분할·그룹 ID가 있다. `split_report.json`에는 포맷별 승패·비율·중복 검사가 있다.

이 파일 전체를 그대로 모델 입력에 넣지 않는다. 관리 정보와 winner·y를 구분하고, 변환 규칙을 학습할 때는 train만 사용한다. validation은 설정 선택, test는 최종 평가에 사용한다.
